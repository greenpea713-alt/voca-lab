# YUMIN GRE Vocab Lab

13주 GRE Verbal 어휘(908개) 학습용 웹앱. 서버 없이 HTML·CSS·JavaScript로만 동작하고, Vercel로 배포한다.

## 주요 기능
- **단어 카드**: 주차별 / 오답만 / 아직 외우지 않은 단어, 무작위 섞기, 발음 듣기, 뜻·예문·표현·어원
- **단어 검색**: 영단어·뜻으로 검색
- **단어 시험**: 10~200문항, 방향 선택
  - 한→영: 한국어 뜻 → 영어 입력, 동의어 그룹 정답 인정(`words.json`의 `syn`), 철자 오류 별도 표시
  - 영→한: 영어 단어 → 한국어 뜻 입력, 끝말 차이(냉소적인=냉소적=냉소)·비슷한 표현·동의어의 뜻 인정, 결과 화면에서 '맞은 걸로' 수동 정정
- **학습 기록**: 점수 추이, 시험별 기록 (브라우저 localStorage 저장)
- **백업**: 기록을 JSON 파일로 내보내고 다른 기기에서 불러와 합치기

## 파일 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인 |
| `app.js` | 기능 (카드·시험·기록·백업) |
| `words.json` | 단어 데이터 (908개, 13주 분류) |

## 실행 방법
- 웹: Vercel 배포 주소로 접속
- 내 컴퓨터: `words.json`을 fetch로 불러오므로 파일을 더블클릭하면 안 열린다. 폴더에서 `python3 -m http.server` 실행 후 http://localhost:8000 접속
- 단어 수정: `words.json`만 고쳐서 GitHub에 올리면 Vercel이 자동 재배포
